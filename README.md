# EXEC_FILE_RENAME 说明书

批量改文件名。一次最多 500 个。

## 启动

双击 `EXEC_FILE_RENAME.bat`。需已安装 Python 3。

## 怎么用

1. 点「添加文件 / 添加文件夹」，或把文件拖进窗口。当前名只出现在左边。
2. 右边大框按行写新文件名（可整列粘贴）。第 N 行对应第 N 个文件。
3. 确认底部行数一致，点「预览对应关系」检查，再点「一键替换」。

右边也可以不填：勾选「格式」选 `001`，会自动变成 `001`、`002`…

添加文件夹只收该层文件，不含子文件夹。

## 按钮

| 按钮 | 作用 |
|------|------|
| 右侧填入当前名 | 把左边名字拷到右边，方便改 |
| 复制左侧 | 复制当前文件名 |
| 写入右侧 | 按已勾选的格式/前缀，先生成到右边 |
| 撤销上次替换 | 还原上一次改名 |

勾选「新名无扩展名时保留原扩展名」时，右边只写 `歌名` 会自动加上原来的 `.mp3` 等后缀。

## 格式 / 前缀

两个勾选互相独立，可单开，可一起开。

- **格式**：`01. ` / `01-` / `01_` / `001`，旁边「起始」是第一项的编号。
- **自定义前缀**：固定文字，如 `封面_`。

两边都开、右边留空、格式选 `001`：`封面_001.mp3`、`封面_002.mp3`。

## 注意

- 左右行数必须一致（右边留空且已勾选格式/前缀时除外）。
- 新名不能含 `\ / : * ? " < > |`，不能为空，不能以空格或点结尾。
- 目标文件已存在则跳过该项。
- 改名失败会尝试还原。
