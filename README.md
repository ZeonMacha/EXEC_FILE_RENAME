# EXEC_FILE_RENAME

Windows 下的文件名批量修改器。左边显示当前文件名，右边一个大框填写新文件名（每行一个，和第 N 个文件对应），点「一键替换」完成改名。

一次最多 **500** 条。

## 运行

需要已安装 Python 3（自带 tkinter）。

- 双击 `EXEC_FILE_RENAME.bat`
- 或在本目录执行：`python EXEC_FILE_RENAME.py`

可把文件或文件夹直接拖进窗口。添加文件夹时，只收取该层文件，不递归子目录。

可选：安装 `tkinterdnd2` 后拖放更稳，不装也能用系统拖放。

```text
pip install tkinterdnd2
```

## 基本用法

1. 「添加文件」或「添加文件夹」，或拖入。当前名出现在**左边**，右边保持空白。
2. 在**右边大框**按行粘贴新文件名（可从 Excel / 记事本整列粘贴）。
3. 看底部计数：左右行数要一致。
4. 可先点「预览对应关系」，再点「一键替换」。

右侧也可以留空：勾选「格式」（例如 `001`）后，会按序号自动生成新名。

## 可选功能

「格式」和「自定义前缀」是两个独立勾选，可单用，也可一起用。

**格式**（加序号）

| 选项 | 示例（右侧留空、保留扩展名） |
|------|------------------------------|
| `01. ` | `01.mp3`、`02.mp3`（点后空格在仅序号时会去掉尾部非法点） |
| `01-` | `01-.mp3`、`02-.mp3` |
| `01_` | `01_.mp3`、`02_.mp3` |
| `001` | `001.mp3`、`002.mp3` |

「起始」决定第一项从几号开始。

**自定义前缀**

在前缀框填写固定文字，例如 `封面_`。与 `001` 一起用、右侧留空时得到：

- `封面_001.mp3`
- `封面_002.mp3`

「写入右侧」会把生成结果先填进右边大框，方便检查后再替换。

其它：

- **新名无扩展名时保留原扩展名**（默认开启）：右边只写 `歌名` 会变成 `歌名.mp3`
- **右侧填入当前名**：把左边文件名复制到右边再改
- **复制左侧**：把当前文件名拷到剪贴板
- **撤销上次替换**：还原上一次成功的批量改名

## 规则与安全

- 左右按行对应，行数不一致会拒绝执行。
- 新名不能包含 `\ / : * ? " < > |`，不能为空，不能以空格或点结尾。
- 目标已存在且不是本批要改走的文件时会拦住。
- 交换文件名（A→B、B→A）会先改成临时名再落到最终名，避免互相覆盖。
- 中途失败会尝试把已改的文件滚回去。

## 界面

- 白框内滚轮：只滚该列表。
- 结果栏内滚轮：只滚结果。
- 「结果」固定在窗口底部，缩小窗口也能看到。
- 列表右侧、底部有滚动条，文件一多即可拖动。
