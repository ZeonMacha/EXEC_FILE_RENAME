# EXEC_FILE=RENAME/. 使用说明

## 1. 概述

EXEC_FILE=RENAME/. 是一款 Windows 平台下的文件名批量修改工具。
窗口标题与界面显示此真实名称。因 `=`、`/` 不能用于进程名和文件名，文件夹、脚本和任务管理器中仍为 `EXEC_FILE_RENAME`。
程序界面左侧显示当前文件名，右侧编辑区用于填写目标文件名。
每个文件名占一行，与左侧文件按行号一一对应。
单击「一键替换」后执行批量重命名。

- 单次最多处理 **500** 个文件。
- 支持直接拖入文件或文件夹。
- 添加文件夹时，仅读取该文件夹第一层文件，不递归处理子文件夹。

---

## 2. 运行环境与启动方式

### 运行环境

- Windows 操作系统
- Python 3（需包含 tkinter，通常随 Python 官方安装包自带）

### 启动方式

以下两种方式任选其一：

- 双击 `EXEC_FILE_RENAME.bat`
- 或在程序所在目录执行命令：

```bash
python EXEC_FILE_RENAME.py
```

### 可选依赖

建议安装 `tkinterdnd2`，可获得更稳定的拖放体验；未安装时仍可使用系统拖放功能。

```bash
pip install tkinterdnd2
```

## 3. 界面说明

| 区域 | 说明 |
|------|------|
| 左侧列表 | 显示当前文件名，即待修改的源文件名 |
| 右侧编辑区 | 填写目标文件名，每行一个，与左侧文件按行对应 |
| 底部计数 | 显示左右两侧行数，执行前应保持一致 |
| 结果区域 | 固定于窗口底部，显示操作结果 |

主要按钮包括：

- 添加文件
- 添加文件夹
- 预览对应关系
- 一键替换
- 写入右侧
- 右侧填入当前名
- 复制左侧
- 撤销上次替换

## 4. 基本操作流程

1. **添加文件**  
   单击「添加文件」或「添加文件夹」，也可以将文件或文件夹直接拖入窗口。  
   添加后，源文件名显示在左侧列表，右侧编辑区保持空白。

2. **填写新文件名**  
   在右侧编辑区按行输入或粘贴新文件名。每行对应左侧同一行文件。  
   可从 Excel、记事本等程序中整列复制后粘贴。

3. **核对行数**  
   查看底部计数，确认左右两侧行数一致。

4. **预览对应关系**  
   可选操作。单击「预览对应关系」检查新旧文件名映射是否正确。

5. **执行替换**  
   确认无误后，单击「一键替换」完成批量重命名。

## 5. 自动编号与自定义前缀

当右侧编辑区留空时，可启用自动编号或自定义前缀功能。若右侧已手动填写文件名，则按右侧内容执行。

「格式」和「自定义前缀」为两个独立选项，可单独使用，也可同时使用。

### 5.1 格式（自动编号）

勾选「格式」后，程序将按序号生成新文件名。「起始」值决定第一个文件从几号开始。

| 格式选项 | 示例输出（右侧留空、保留原扩展名） | 说明 |
|------|------------------------------|------|
| `01.` + 空格 | `01.mp3`、`02.mp3` | 末尾的句点与空格会被自动移除 |
| `01-` | `01-.mp3`、`02-.mp3` | 无 |
| `01_` | `01_.mp3`、`02_.mp3` | 无 |
| `001` | `001.mp3`、`002.mp3` | 无 |

### 5.2 自定义前缀

在前缀输入框中填写固定文字，例如：

```text
封面_
```

与格式 `001` 同时使用，且右侧留空时，生成结果示例：

```text
封面_001.mp3
封面_002.mp3
```

单击「写入右侧」可将自动生成的结果填充到右侧编辑区，便于在替换前检查。

## 6. 其他功能

- **保留原扩展名**（默认开启）  
  如果新文件名未包含扩展名，程序会自动沿用源文件扩展名。  
  示例：右侧仅填写 `歌名`，实际生成文件名为 `歌名.mp3`。

- **右侧填入当前名**  
  将左侧源文件名复制到右侧编辑区，便于在此基础上修改。

- **复制左侧**  
  将当前源文件名复制到剪贴板。

- **撤销上次替换**  
  还原最近一次成功执行的批量重命名操作。

## 7. 命名规则与安全机制

- **行数校验**  
  左右两侧行数必须一致，否则程序拒绝执行。

- **非法字符限制**  
  目标文件名不得包含以下字符：

  ```text
  \ / : * ? " < > |
  ```

- **结尾限制**  
  目标文件名不能为空，不能以空格或句点结尾。

- **目标冲突检测**  
  若目标文件名已被现有文件占用，且该文件不属于本次操作中将被改名的源文件，程序会阻止执行，避免覆盖。

- **交换文件名处理**  
  当出现类似 A→B、B→A 的交换式重命名时，程序会先使用临时文件名过渡，再改为最终名称，避免相互覆盖。

- **失败回滚**  
  若执行过程中发生错误，程序会尝试将已改名的文件恢复为原名称。

## 8. 界面操作细节

- 左侧列表和结果区域支持独立滚轮滚动。
- 结果区域固定于窗口底部，窗口缩小时仍可查看。
- 列表右侧及底部提供滚动条，文件数量较多时可拖动查看。
